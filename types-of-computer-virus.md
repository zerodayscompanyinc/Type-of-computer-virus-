# Types of Computer Virus

**Small Code. Big Damage.**

![Computer virus detected on a laptop](PASTE_IMAGE_URL_HERE)

*Find an image: [Google Images](https://www.google.com/search?tbm=isch&q=computer+virus+detected+laptop)*

A computer virus is a malicious program that can copy itself and move from one computer to another. It can cause unwanted changes, data loss, slow performance, or damage to the whole system.

## What Is a Computer Virus?

A virus is a type of malware that attaches itself to a file or program. It spreads when that file is run, often without the user knowing.

---

## Common Types of Computer Viruses

### 1. Boot Sector Virus

Infects the boot sector of a disk. It loads into memory when the computer starts and can stop the operating system from loading.

![Boot Sector Virus](PASTE_IMAGE_URL_HERE)

*Find an image: [Google Images](https://www.google.com/search?tbm=isch&q=boot+sector+virus+hard+disk)*

### 2. File Infector Virus

Attaches itself to executable files such as .exe or .com. It spreads when the infected file is run.

![File Infector Virus](PASTE_IMAGE_URL_HERE)

*Find an image: [Google Images](https://www.google.com/search?tbm=isch&q=file+infector+virus+exe)*

### 3. Macro Virus

Written in a macro language such as VBA. It infects documents like Word or Excel files.

![Macro Virus](PASTE_IMAGE_URL_HERE)

*Find an image: [Google Images](https://www.google.com/search?tbm=isch&q=macro+virus+word+excel)*

### 4. Multipartite Virus

Infects both boot sectors and files. Because it spreads in several ways, it is harder to remove.

![Multipartite Virus](PASTE_IMAGE_URL_HERE)

*Find an image: [Google Images](https://www.google.com/search?tbm=isch&q=multipartite+virus)*

### 5. Polymorphic Virus

Changes its code structure every time it infects a file, so antivirus programs have a harder time detecting it.

![Polymorphic Virus](PASTE_IMAGE_URL_HERE)

*Find an image: [Google Images](https://www.google.com/search?tbm=isch&q=polymorphic+virus)*

### 6. Metamorphic Virus

Rewrites all of its code each time it infects something, which makes it even harder to detect and remove.

![Metamorphic Virus](PASTE_IMAGE_URL_HERE)

*Find an image: [Google Images](https://www.google.com/search?tbm=isch&q=metamorphic+virus)*

### 7. Resident Virus

Installs itself in system memory and stays active, infecting files for as long as the system is running.

![Resident Virus](PASTE_IMAGE_URL_HERE)

*Find an image: [Google Images](https://www.google.com/search?tbm=isch&q=resident+virus+memory)*

### 8. Direct Action Virus

Doesn't hide in files to spread. It carries out its harmful action as soon as it is run.

![Direct Action Virus](PASTE_IMAGE_URL_HERE)

*Find an image: [Google Images](https://www.google.com/search?tbm=isch&q=direct+action+virus)*

### 9. Overwrite Virus

Writes over the content of files, destroying the original data.

![Overwrite Virus](PASTE_IMAGE_URL_HERE)

*Find an image: [Google Images](https://www.google.com/search?tbm=isch&q=overwrite+virus+file)*

### 10. Companion Virus

Creates a file with the same name as a real program but with a different extension.

![Companion Virus](PASTE_IMAGE_URL_HERE)

*Find an image: [Google Images](https://www.google.com/search?tbm=isch&q=companion+virus)*

### 11. Stealth Virus

Hides itself by intercepting system calls and concealing the changes it makes.

![Stealth Virus](PASTE_IMAGE_URL_HERE)

*Find an image: [Google Images](https://www.google.com/search?tbm=isch&q=stealth+virus)*

### 12. Armor Virus

Uses advanced techniques to disguise its code and resist analysis and detection.

![Armor Virus](PASTE_IMAGE_URL_HERE)

*Find an image: [Google Images](https://www.google.com/search?tbm=isch&q=armored+virus+malware)*

## How Do Viruses Spread?

![How computer viruses spread](PASTE_IMAGE_URL_HERE)

*Find an image: [Google Images](https://www.google.com/search?tbm=isch&q=how+computer+viruses+spread+infographic)*

- Infected email attachments
- Downloading from untrusted websites
- Using infected USB drives
- Sharing files and pirated software
- Exploiting system vulnerabilities

## Prevention Tips

![Antivirus protection shield](PASTE_IMAGE_URL_HERE)

*Find an image: [Google Images](https://www.google.com/search?tbm=isch&q=antivirus+protection+shield)*

- Use up-to-date antivirus software
- Keep your operating system and apps updated
- Avoid suspicious links and downloads
- Scan USB and external drives
- Turn on a firewall and use strong passwords
- Back up important data regularly

## Did You Know?

The first computer virus, called "Creeper," was created in the 1970s as an experiment, not to cause harm.
